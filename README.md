A clean, modern, and visually polished one-page printable CV tailored for tuition teaching, academic tutoring, and ICT/Computer instruction positions.

---

## 🌟 Key Features

- **Strict 1-Page A4 Precision:** Engineered with dedicated `@page` and `@media print` rules for 100% single-page PDF export without overflow or cutoffs.
- **Academic & Trustworthy Aesthetic:** Designed specifically to communicate conceptual clarity, patience with students, and strong IT/computing competence.
- **Interactive Control Bar:**
  - 🎨 **Palette Switcher:** Academic Navy (Default), Classic Slate, Oxford Emerald, and Regal Burgundy.
  - 📷 **Live Photo Upload:** Upload or change photo dynamically with persistent localStorage saving.
  - ✏️ **Live Inline Text Edit:** Click-to-edit any text on the CV in real-time before printing.
  - 🖨️ **1-Click Print / Save as PDF:** Pre-configured print dialog trigger.

---

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Pawan131-web/Portfolio.git
   cd Portfolio
   ```
2. Open `index.html` directly in any web browser, or run a local server:
   ```bash
   python -m http.server 8080
   ```
3. Open `http://localhost:8080` in your browser.

---

## 📄 PDF Export Instructions
1. Click **"Print / Save as PDF"** on the top toolbar (or press `Ctrl + P`).
2. In the Print Dialog:
   - **Destination:** Save as PDF
   - **Paper Size:** A4
   - **Margins:** Default / None
   - **Options:** Check *Background graphics*
3. Save your clean, professional 1-page CV.
