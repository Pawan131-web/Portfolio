> **Full-Stack Web Developer &bull; BIM Student &bull; Academic & ICT Mentor**  
> Pokhara, Nepal &bull; [GitHub](https://github.com/Pawan131-web) &bull; [LinkedIn](https://www.linkedin.com/in/pawan-rimal-225a5b35b/)

A modern, high-performance, dark-mode first personal portfolio website for **Pawan Rimal**, showcasing full-stack web engineering projects, interactive developer CLI terminal, bento skills grid, tutoring methodology, and an integrated 1-page A4 printable CV engine.

---

## 🌟 Key Features

- **🌙 OLED Dark Mode (Default) & Light Mode:**
  - High-contrast, eye-friendly OLED dark theme with glowing neon accents.
  - Seamless toggle with persistent `localStorage` memory and smooth CSS transitions.

- **💻 Interactive Live CLI Developer Terminal Widget:**
  - Live command execution right in the hero section (`help`, `bio`, `skills`, `projects`, `contact`, `cv`, `socials`, `clear`, `date`).
  - Quick-action chips for rapid interaction.

- **✨ Rich Aesthetics & Micro-Interactions:**
  - Glassmorphic navigation bar with scroll-aware active section tracking.
  - Floating ambient light orbs and smooth hover states.
  - Dynamic typewriter effect highlighting multifaceted roles.

- **🚀 Featured Projects Showcase & Category Filters:**
  - **DreamSky Consultancy CRM System** (Production CRM & Student Records Platform)
  - **Annapurna Groceries** (Modern E-Commerce Web App)
  - **Academic 1-Page CV Engine** (Precision A4 Single-Page Builder with PDF export)
  - **Full-Stack REST APIs & MERN Solutions**

- **🧩 Bento Grid Capabilities & Skills:**
  - Visual classification across Frontend, Backend & Database, Dev Tools, and ICT/Mentorship.

- **🎓 Academic Tutoring & ICT Mentorship Section:**
  - Highlights concept-first clarity, patient pacing, practical IT integration, and structured lesson design.

- **📬 Direct Connect & Working Contact Form:**
  - 1-click clipboard copy for phone and email with animated toast notifications.
  - Interactive contact form with input validation and instant `mailto:` generation.

- **📄 Embedded 1-Page A4 Printable CV Modal:**
  - Preserved single-page precision layout with dedicated `@page` and `@media print` rules for flawless PDF download.

## 🛠️ Tech Stack

- **Structure:** Semantic HTML5 (WAI-ARIA accessible)
- **Styling:** Vanilla CSS3 (Custom properties, CSS Grid, Flexbox, Glassmorphism, Print rules)
- **Scripting:** Modern Vanilla JavaScript (ES6+, DOM manipulation, IntersectionObserver, Clipboard API)
- **Fonts:** Space Grotesk, Plus Jakarta Sans, Inter, JetBrains Mono (via Google Fonts)

## 🚀 How to Run Locally

1. Clone or open the repository:
   ```bash
   git clone https://github.com/Pawan131-web/Portfolio.git
   cd Portfolio
   ```

2. Run a local web server (Python, Node, or VS Code Live Server):
   ```bash
   # Using Python:
   python -m http.server 8080
   ```

3. Open `http://localhost:8080` (or double-click `index.html`) in any modern web browser.
